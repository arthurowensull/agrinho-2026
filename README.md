# AGROBALANCE AI

**Slogan:** "Produzir mais não significa produzir melhor."

Projeto desenvolvido para o **Agrinho Programação 2026** com o tema **Produção e Preservação através da Agricultura Inteligente**.

## Descrição

O AGROBALANCE AI é uma plataforma web simulada de monitoramento agrícola. O site representa uma central de comando de uma fazenda inteligente, usando dados simulados de sensores IoT, histórico em PostgreSQL, análise por IA e recomendações sustentáveis.

A proposta mostra que a tecnologia pode ajudar produtores rurais a equilibrar produtividade, preservação ambiental, uso racional da água, fertilidade do solo e biodiversidade.

## Objetivo no tema Agrinho

O objetivo educacional é demonstrar que produzir mais nem sempre significa produzir melhor. A plataforma simula decisões agrícolas e mostra como cada escolha pode afetar solo, água, biodiversidade, produtividade e preservação.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript puro
- Canvas nativo do HTML

O projeto **não usa frameworks, bibliotecas externas, CDN, Bootstrap, Tailwind, React, Vue, jQuery, Chart.js ou bibliotecas de ícones/animações**.

## Funcionalidades

- Hero imersivo com visual de central agrícola inteligente.
- Missão do Produtor com objetivos de equilíbrio sustentável.
- Centro de Decisões AgroBalance com indicadores dinâmicos.
- Índice AgroBalance calculado por JavaScript.
- Balança Produção vs Preservação com ações interativas.
- Simulador de Cenários Agrícolas.
- Fazenda Digital Interativa com setores clicáveis.
- Gráfico simulado em Canvas.
- Centro de Alertas Inteligentes com tipo, nível, horário, mensagem e recomendação.
- Histórico Inteligente atualizado por JavaScript.
- Fluxo técnico: Sensor IoT → PostgreSQL → Motor de Análise AgroBalance AI → Decisão do Produtor.
- Assistente AgroBalance com respostas simuladas.
- Relatório Final da Fazenda.
- Alto contraste, aumentar fonte, diminuir fonte e voltar ao topo.
- Controle de intensidade de efeitos visuais.

## Como Usar

1. Abra o arquivo `index.html` em um navegador moderno.
2. Use os botões do menu para navegar pelas seções.
3. Clique nos cenários agrícolas para alterar os dados da fazenda.
4. Use a Balança AgroBalance para testar decisões.
5. Clique nos setores do mapa para ver dados específicos.
6. Gere diagnóstico e relatório para visualizar a análise da IA simulada.
